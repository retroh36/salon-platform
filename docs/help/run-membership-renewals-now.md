Renewals run by themselves every night. You can run whatever is due right now.

1. In the sidebar, tap **Settings**, then **Memberships**.
2. Under **Renewals**, tap **Run renewals now**.
3. Read the result: how many renewed, failed, paused, resumed and ended, or "Nothing is due right now."

## Good to know

- It only charges payments that are due, so running it twice never charges anyone twice.
- Payments are in test mode for now: renewals go through a test provider and no real card is charged.
- To fix one client's failed payment, see Update a membership's card or retry a failed payment.
