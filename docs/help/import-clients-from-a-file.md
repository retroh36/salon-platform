Bring your client list over from a CSV file.

1. Go to **Settings** and tap **Import clients**.
2. Under **CSV file**, choose your file. It needs a header row.
3. Check each field has the right column, and change any that don't. **First name** or **Full name** is needed; the rest are optional.
4. Read the line saying how many will be imported and any rows with a problem, and look over the first few clients.
5. Tap **Import**.

## Good to know

- Anyone already here with the same phone or email is left exactly as they are. The same goes for someone with the same name when neither has a phone or email.
- Running the same file again adds nobody twice.
- Everyone added gets visit messages as usual and no offers until they say yes.
- A phone, email or birthday that can't be read is left off, and the client is still added. A row with no name is skipped.
- To take an import back, tap **Undo** under **Past imports**. Clients who've had a visit or a sale since stay.

## If it doesn't work

- "That file has no rows to import": save it as a CSV with a header row, then try again.
