Undo a whole sale that was rung up by mistake, so the visit can be checked out again.

1. Go to **Sales** and tap the sale (see Find a past sale).
2. Under **Void**, type **Why it's being voided**.
3. Tap **Void sale**.
4. The sale shows **Voided**. If it was a visit, open it on the calendar and tap **Check out** to ring it up again.

## Good to know

- Voiding reverses every payment, puts products back in stock, gives package and membership uses back, and reopens the visit.
- Only sales with no refunds can be voided. For part of a sale, see Refund a sale.
- Card payments are reversed on the salon's own terminal; here you record it.
- The front desk can't void; ask a manager or owner.

## If it doesn't work

- "A gift card from this sale has been used, so it can't be voided. Refund instead.": refund the rest instead.
- "A package from this sale has been used…": cancel the package from the client's profile instead.
