Pay for a service with one use of the client's package.

1. In booking details, tap **Check out**.
2. Look at the service line: if the client's package covers it, it's already ticked and says **paid with package**.
3. If it isn't (for example a service you added at checkout), tap **Package** under **Payment**.
4. Tap the service to pay for with the package. The list shows how many uses are left.
5. If the client doesn't want to use the package for it, tap the line and tap **Don't use the package for this**. It goes back to its price, and the use stays on the package.
6. Pay anything else on the ticket as usual, then tap **Complete sale**.

## Good to know

- The client's package uses show as a "Package" badge next to their name.
- One use covers one service. It isn't taxed or discounted.
- The package must cover that service and that stylist's level, and not have expired. When there's a choice, the one that expires soonest is used first.
- If the sale is voided, the use goes back on the package. Package uses are never refunded as money.

## If it doesn't work

- **Package** is greyed out: no service on the ticket is covered by the client's packages (wrong service, stylist level, expired, or none left).
