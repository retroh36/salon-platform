Ask for time off. Managers and owners can also add approved time off for anyone.

1. In the sidebar, tap **Team**, then the **Schedule** tab. It opens on your own schedule.
2. Managers: to add time off for someone else, tap their name at the top.
3. Scroll to **Time off**.
4. Choose the **First day**. Set the **Last day**, or leave it blank for one day.
5. For part of a day, tick **Part of the day** and set **From** and **To**.
6. Choose a **Reason** and add a **Note (optional)**.
7. Tap **Request time off** (or **Add time off** if you're a manager or owner).

## Good to know

- Requests show as **Pending** until a manager or owner approves them. See "Approve time off".
- Only approved time off blocks bookings.
- You can **Withdraw** your own request while it's still pending.
- Time off a manager adds is approved straight away.
- If a stylist is out unexpectedly today, see "Mark a stylist out for the day" so Denise can move their clients.
