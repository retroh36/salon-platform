Choose how long a patch test lasts, how long before the service it must be done, and whether a missing one blocks the booking.

1. Go to **Forms** in the sidebar (patch test rules are there, not in Settings).
2. Scroll to **Patch tests**.
3. Set **Valid for** (months).
4. Set **Done at least** (hours before the service).
5. Under **When a client's patch test is missing, expired or too recent**, choose **Warn, but allow the booking** or **Don't allow the booking**.
6. Tap **Save patch test rules**.

## Good to know

- Which services need a patch test is set on each service, under **Services**.
- With **Don't allow the booking**, a client can't be checked in until their patch test is in order; a manager or owner can check them in anyway with a reason, and it's logged.
- Online, a service that needs a patch test is always blocked until the test is in order, whatever you choose here.
- Everyone can see these rules; only owners and managers can change them.
