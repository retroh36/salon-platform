Sell a client a set of services up front at one price, to use over several visits.

1. Open the checkout: tap **Check out** in booking details, or **New sale** on **Sales**.
2. For a new sale, find the client with **Find a client** at the top (a package needs a client).
3. Under the lines, tap **Package**.
4. Tap the package the client wants. It's added to the ticket.
5. Take payment under **Payment** (**Card**, **Cash** or **Gift card**).
6. Tap **Complete sale**.

## Good to know

- The **Package** button only shows when an owner has set up packages on Settings, Packages.
- Packages are taxed like services.
- Once sold, the uses show on the client's profile under **Packages**, and on the checkout as a "Package" badge next to their name.
- If the sale is voided, an unused package is canceled. To use it, see Use a package at checkout.

## If it doesn't work

- The packages are greyed out with "Packages need a client on the sale": add the client first.
