Record a patch test once it's been done, so color services can go ahead.

1. Open the client's profile (search for them under **Clients**), or open their visit in booking details on the calendar.
2. On the profile, tap the **Patch tests** tab, then **Add patch test**. In booking details, tap **Before this visit** and then **Record patch test**.
3. Set the **Date** and **Time** of the test. They start on today at 10am, or the time now if it's earlier: a test can't be recorded before it's done.
4. Choose who did it under **Done by**.
5. Choose the **Result**: **No reaction** or **Reaction**.
6. Enter the **Products tested**, and any **Notes (optional)**.
7. Tap **Record patch test**. On the profile, the form closes and the test is listed.

## Good to know

- Record it after the test is done, not before. A test can't be dated in the future.
- Stylists record patch tests for their own clients (anyone booked with them); the front desk, managers and owners for anyone.
- The profile says whether the client's patch test is valid today. Past tests are listed with their result.
- Which services need a patch test, how long one lasts, and whether a missing one blocks booking are set by the owner (see Set patch test rules).
- If the salon requires one and it's missing, the client can't be booked or checked in. A manager or owner can check them in anyway with a reason.
