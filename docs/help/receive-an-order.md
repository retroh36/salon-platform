When a delivery arrives, check it against the order to add it to stock.

1. In the sidebar, tap **Inventory**, then **Orders**.
2. Tap the order (it says **Sent** or **Partly received**).
3. Under **Receive delivery**, check each product. **Arrived** starts at what's due; change it to what actually came.
4. Tap **Receive into stock**.

## Good to know

- Stock goes up straight away, and the cost on the order becomes the product's cost.
- If only part arrived, the order shows **Partly received**. Receive the rest the same way when it comes.
- You can't receive more than was ordered, or receive an order that hasn't been marked as sent.
