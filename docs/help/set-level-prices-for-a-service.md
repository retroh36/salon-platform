Charge a different price for a service depending on the stylist's level.

1. In the sidebar, tap **Services**.
2. Tap the service.
3. Under **Prices by level**, enter a price for **Artisan ($)**, **Senior ($)** and **Master ($)**. Leave one blank to use the default price for that level.
4. Tap **Save changes**.

## Good to know

- A stylist's own price, set under **Who offers this**, beats their level's price.
- The Services list shows the range of prices the stylists charge.
- Online booking shows each stylist's price, and a price range for the service.
- To set a stylist's level, see "Set a stylist's level".
