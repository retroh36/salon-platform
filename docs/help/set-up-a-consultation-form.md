Build the consultation and consent forms clients fill in and sign.

1. Go to **Forms** and tap **New form** (or tap an existing form to change it).
2. Enter the **Name** and an **Introduction for the client (optional)**.
3. Under **Questions**, type each **Question** and choose its **Type**. Tick **Required** for must-answer questions.
4. Add more with **+ Text answer**, **+ Checkbox**, **+ Yes / no** or **+ Signature**. Use the arrows to reorder, or **Remove**.
5. Under **When it's needed**, choose **Optional: fill in whenever**, **Before a client's first visit** or **Before certain services** (then tick the services).
6. Keep **In use** ticked, then tap **Create form** (or **Save form**).

## Good to know

- A form can have one signature.
- When a form is needed, booking details shows it under **Before this visit** until it's signed, and check-in warns about it.
- Untick **In use** to stop using a form. Forms already signed stay on clients' profiles.
- Everyone can see the Forms page; only owners can change it.
- Patch test rules are on the same page (see Set patch test rules).
